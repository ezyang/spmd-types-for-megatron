Using spmd_types in Megatron

spmd_types is a type system for distributed tensor computations. It helps solve two specific problems that commonly arise when writing distributed code:

  1. When using differentiable collectives (e.g., as popularized by Megatron-style tensor parallelism), forgetting to insert an appropriate backward collective (no-op in forwards) will result in silently incorrect gradients. spmd_types keeps track of whether or backward gradients have pending reductions, allowing us to verify correct use of collectives. This is local SPMD typechecking.
  2. When writing distributed code, some functions have the same semantics no matter the choice of parallelism (e.g., "single device" code that trivially parallelizes), while other functions (e.g., "local map" regions) have semantics that change depending on the parallelism, as they are specifying computation that happens on a per-rank basis that doesn't commute with changes in sharding. A way to introduce a silent correctness is to write code without realizing it is not parallelism-invariant (e.g., doing a reduction on a sharded dimension, that requires a further distributed reduction.) If you are writing spmd_types you can explicitly specify if code is intended to be parallelism-invariant, and spmd_types will report if it's unable to prove that you've done this safely. As an auxiliary benefit, spmd_types SPMD type tells you how to reassemble the global tensor from the local shards. This is global SPMD typechecking.

We recently rewrote torchtitan to make use of spmd_types instead of DTensor, with the goal of making it more obvious when collectives occur in torchtitan model code. However, spmd_types is designed to be easy to retrofit in a variety of different codebases. In this post, we show how to integrate it with Megatron (but the learnings are applicable to any Megatron-style codebase.) The general recipe is:

  1. Make your codebase support fake process group, if it doesn't already. This allows you to run your full-size model code on a single GPU, which is good for testing and memory analysis. (Megatron already supports this, so it is omitted in this post.)
  2. For each custom autograd function in your codebase, either decorate it with register_local_autograd_function (if it's a purely local autograd function and you only care about local SPMD typechecking) or add a static method spmd_typecheck describing its typing rule (if it's a distributed collective, or it's local but you want to do global SPMD typechecking).
  3. Write rules for annotating all of the parameters of your model with appropriate types. This requires knowing a little bit about how your distributed wrappers (e.g., FSDP) work. If you use stock PyTorch FSDP2 on PyTorch 2.14.0 or later, this is automatically handled for you. Megatron has a custom FSDP implementation, so in this post we'll show how it was adjusted to handle this.
  4. Write a unit test (with fake PG) which runs your model code with typechecking enabled.

+def _tensor_parallel_type(tensor: torch.Tensor) -> spmd.SpmdType:
+    """Infer a parameter's TP type from Megatron's distribution metadata.
+
+    ``megatron.core.tensor_parallel.layers.set_tensor_model_parallel_attributes``
+    marks physically sharded parameters with ``tensor_model_parallel`` and records
+    their global shard dimension in ``partition_dim``. Column-parallel weights use
+    dimension 0, while row-parallel weights use dimension 1.
+
+    ``sequence_parallel`` means something different when attached to a
+    parameter: the parameter value is replicated, but each TP rank accumulates
+    a gradient from its local sequence shard. The
+    ``_allreduce_non_tensor_model_parallel_grads`` helper in
+    ``megatron.core.distributed.finalize_model_grads`` reads this attribute and
+    sums those partial gradients across TP, which is exactly the R (replicated
+    value, partial gradient) contract.
+
+    Other trainable parameters are invariant across TP. Non-trainable tensors
+    are treated as replicated because only their forward value matters.
+    """
+    if getattr(tensor, "tensor_model_parallel", False):
+        return spmd.S(getattr(tensor, "partition_dim"))
+    if getattr(tensor, "sequence_parallel", False):
+        return spmd.R
+    return spmd.I if tensor.requires_grad else spmd.R
